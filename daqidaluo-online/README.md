# 《大起大落》联机版

多人实时对赌版：一台电脑开服务器，朋友们手机/电脑连同一个 WiFi，浏览器里建房 → 输码加入 → 一起玩。

**零依赖**：只用 Node.js 自带模块，不用 `npm install`。

## 文件结构

| 文件 | 作用 |
|---|---|
| `server.js` | 服务器（HTTP + SSE 推送 + 操作接口） |
| `engine.js` | 纯逻辑引擎（随机数、算钱、判谁赢，全在这里） |
| `public/index.html` | 客户端界面 |
| `public/client.js` | 客户端逻辑（只负责显示 + 发指令） |
| `public/style.css` | 样式 |

## 怎么跑（局域网）

1. 装好 Node.js（nodejs.org，装 LTS 版即可）。
2. 在这个文件夹打开命令行，运行：
   ```
   node server.js
   ```
3. 看到「已启动」后，**本机**浏览器打开 `http://localhost:3000`。
4. 想让朋友加入：告诉他们**你的局域网 IP**（同一 WiFi 下）。查 IP 的方法：
   - Windows：命令行输入 `ipconfig`，找「IPv4 地址」，形如 `192.168.x.x`；
   - 朋友在浏览器打开 `http://你的IP:3000`。
5. 你点「创建房间」拿到 4 位房间码，朋友输码加入，人齐了房主点「开局」。

> 如果朋友打不开，多半是 Windows 防火墙拦了 3000 端口，需要放行。

## 规则

和单机版一致，另有一条联机专属：

- **只剩最后一个人也能继续玩**（一个人照样抛硬币对赌），只有**全部下桌**才结算。
- 结算按 **总资产 = 风浪币 − 负债** 排名（借钱产生的负债要还）。

## 为什么这样设计（给想学的人）

- **服务器权威**：抛硬币的随机数、算钱全在 `engine.js` 里（服务器上），浏览器只是"发指令 + 显示"。这样别人按 F12 也改不了结果 —— 这就是"单机修改器 vs 网游外挂"里说的"在哪算、谁说了算"。
- **零依赖**：不用 WebSocket 库，用浏览器原生的 SSE（服务器单向推送）+ fetch（发指令），少一层黑盒。
- **断线 15 秒宽限**：手机锁屏/切后台断连后 15 秒内回来还能续上，超时才按撤离处理。

## 上公网（可选）

局域网只能同一 WiFi 玩。想让外地朋友也玩，把 `server.js` 部署到能跑 Node 的平台（Render / Railway / Fly.io 等免费层即可），拿到公网网址。这步需要注册托管平台账号，按平台文档部署即可。
